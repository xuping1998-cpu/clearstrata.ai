## 8. Idempotency decision table (implementer-ready)

| Case | Conditions | Outcome | Identity reuse |
|------|------------|---------|----------------|
| **1** | Durable authoritative **COMMITTED** freeze exists for meeting | **IDEMPOTENT_RETURN** | Return **existing** committed ids |
| **2** | No durable committed freeze **AND** authoritative active owner/attempt | **RETRYABLE** | **No** durable assignment |
| **3** | No durable committed freeze **AND** no active owner **AND** prior attempt terminal (rolled back/abandoned) | **NEW_ATTEMPT_REQUIRED** | **New** attemptId · freezeEventId · primaryAuditId |
| **4** | Commit outcome unknown (timeout / lost ack) | **COMMIT_OUTCOME_UNCERTAIN** → **reconcile** → Case 1, 2, or 3 | Per reconciliation branch |

**Normative exclusions:**

```
RETRYABLE ≠ NEW_ATTEMPT_REQUIRED
IDEMPOTENT_RETURN ≠ "try commit again"
NEW_ATTEMPT_REQUIRED ≠ reuse old identities
```
