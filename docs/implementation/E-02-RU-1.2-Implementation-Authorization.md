## 7. Lock contract (locked)

### 7.1 Ownership mechanism

```sql
pg_try_advisory_xact_lock(
  hashtextextended(
    'e02_owner_vote_freeze:' || p_owner_vote_meeting_id::text,
    0
  )
)
```

| Property | Requirement |
|----------|-------------|
| Scope | Meeting-scoped |
| Lifetime | Transaction-scoped (xact lock) |
| Blocking | **Non-blocking** — try-lock only |
| Lock failure | Return **RETRYABLE** jsonb |
| Blocking lock | **PROHIBITED** |
| Sleep / busy-wait loop | **PROHIBITED** |
| Global lock | **PROHIBITED** |

### 7.2 Durable ownership table

```
DURABLE OWNERSHIP TABLE = NOT AUTHORIZED / NOT REQUIRED
```

**Prohibited:** `owner_vote_freeze_ownership` · `attempt_lock` · `freeze_claims` · lease table · heartbeat table · equivalent.

Architecture: **transient xact lock** + **durable committed A–G reconciliation**.

## 8. Double-check protocol (mandatory — locked)

| Step | Action | Exit |
|------|--------|------|
| 1 | Resolve auth / meeting | EXCEPTION on failure |
| 2 | Initial durable reconciliation | **IDEMPOTENT_RETURN** if full A–G · EXCEPTION if partial |
| 3 | Try advisory xact lock | **RETRYABLE** if unavailable |
| 4 | **Post-lock durable reconciliation** | **IDEMPOTENT_RETURN** if full A–G · EXCEPTION if partial |
| 5 | Validate fresh identities | **NEW_ATTEMPT_REQUIRED** or EXCEPTION per contract |
| 6 | Execute new A–G envelope | EXCEPTION on failure |
| 7 | Return success jsonb | **ATOMIC_ENVELOPE_COMPLETE** |

Post-lock durable double-check **shall not** be simplified or omitted.

## 9. Fresh attempt / identity boundary (locked)

### 9.1 MAY PROCEED

```
no durable full A–G
+ lock acquired
```
