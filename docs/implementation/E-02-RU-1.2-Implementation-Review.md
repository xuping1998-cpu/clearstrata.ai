### 8.3 Return contract (locked)

**Type:** `RETURNS jsonb` — repository precedent (`set_owner_vote_snapshot_freeze_at`)

**Success / idempotency payloads:**

| `outcome` value | When | Required keys |
|-----------------|------|---------------|
| `IDEMPOTENT_RETURN` | Full durable A–G exists | `outcome`, `owner_vote_meeting_id`, `freeze_event_id`, `primary_audit_id`, `property_id` |

## 12. Lock acquisition protocol (locked)

### IR-LOCK-PROTOCOL-001

| Step | Action | Exit |
|------|--------|------|
| **0** | Auth + resolve meeting/property | EXCEPTION on failure |
| **1** | Initial durable reconciliation (read-only) | **IDEMPOTENT_RETURN** if full A–G · EXCEPTION if partial/inconsistent |
| **2** | `pg_try_advisory_xact_lock(lock_key)` | **RETRYABLE** jsonb if `false` |
| **3** | **Post-lock durable double-check (RU-1.2-DC-001)** | **IDEMPOTENT_RETURN** if full A–G now exists · EXCEPTION if partial |
| **4** | Validate supplied identities for fresh envelope | **NEW_ATTEMPT_REQUIRED** or EXCEPTION per §19 |
| **5** | Materialize / verify A → B → C → D → F → E → G | EXCEPTION → rollback on any failure |
| **6** | Final verification | EXCEPTION on failure |
| **7** | Return `ATOMIC_ENVELOPE_COMPLETE` jsonb | — |

### 12.1 Why double-check is mandatory (IR-DC-001)

Race: T1 initial check sees none → T2 acquires lock, commits full A–G, releases lock → T1 acquires lock. Without step 3, T1 would duplicate freeze. **Post-lock reconciliation is mandatory.**

## 18. Fresh attempt vs NEW_ATTEMPT_REQUIRED (IR-IDENTITY-001)

### 18.1 Valid fresh Phase 1 attempt — MAY PROCEED

All must hold:

| # | Condition |
|---|-----------|
| 1 | No full durable A–G for meeting |
| 2 | Lock acquired (step 2–3 passed) |
| 3 | `p_freeze_event_id` **NOT** present in `owner_vote_freeze_events` |
| 4 | `p_primary_audit_id` **NOT** present in `owner_vote_primary_freeze_audits` |
| 5 | `p_attempt_id` **NOT** present in any `owner_vote_primary_freeze_audits.attempt_id` |
| 6 | No partial/inconsistent durable state |
| 7 | Identity / boundary validation passes |

→ Proceed to step 5 materialization.

**Important:** Absence of durable A–G **alone** does **NOT** imply **NEW_ATTEMPT_REQUIRED**. First-ever valid invocation with fresh Phase 1/3 IDs **proceeds**.

### 18.2 Terminal / old identity — NEW_ATTEMPT_REQUIRED

Return jsonb `outcome: 'NEW_ATTEMPT_REQUIRED'` when:

| # | Trigger |
|---|---------|
| 1 | `p_freeze_event_id` already exists in `owner_vote_freeze_events` but full A–G predicate **not** satisfied → if partial, **EXCEPTION** instead; if non-primary orphan event blocking reuse → **NEW_ATTEMPT_REQUIRED** |
| 2 | `p_primary_audit_id` already exists in audits table |
| 3 | `p_attempt_id` already exists in any Primary Audit row |
| 4 | Supplied IDs correlate to abandoned/terminal lifecycle per certified non-reuse (durable collision) |

### 18.3 Rollback / never-attempted distinction

| Case | DB footprint | RPC behavior |
|------|--------------|--------------|
| Never attempted | None | Fresh IDs → **proceed** |
| Fully rolled back | None | Fresh IDs → **proceed** · reused IDs with no footprint → **proceed at DB layer** — Phase 1 orchestration **must** supply new IDs per certified contract |
| Partial / drift | Partial rows | **EXCEPTION** — FAIL CLOSED |

Server **must not** fabricate rollback history. Orchestration enforces identity non-reuse when DB has no durable footprint.
