This document defines **E-02 IU-5.4 — Project Certification** as the formal **Project Certification Evaluation** specification per [`E-02-Phase-5-Implementation-Plan.md`](E-02-Phase-5-Implementation-Plan.md) §IU-5.4 and [`E-02-Implementation-Plan.md`](E-02-Implementation-Plan.md).

**E-02 Project Certification Evaluation Baseline**

1. What are Project Certification mandatory gates?
2. Which gates are satisfied?
3. Which gates are not satisfied?
4. Which are blocked by executable acceptance blockers?
5. Which require explicit authority decision?
6. Is Project Certification issuance currently permitted?
7. If not, what is the formal certification decision?
8. Can Phase 5 complete?
9. Can E-03 unlock?
10. What must be resolved first?

**Core principle:**

```
CERTIFICATION EVALUATION ≠ CERTIFICATION ISSUANCE
IU-5.4 MUST EVALUATE · MUST NOT RE-ADJUDICATE ACCEPTANCE
```

## 4. Project Certification Evaluation Model

Each certification gate **shall** record these **independent** columns:

| # | Column | Definition |
|---|--------|------------|
| 1 | **Certification Gate ID** | PCG-xxx identifier |
| 2 | **Requirement** | What the gate requires |
| 3 | **Source Authority** | Program Plan · Phase Plan · Work Breakdown · Acceptance Report |
| 4 | **Evidence** | Current documented evidence |
| 5 | **Current State** | Factual status |
| 6 | **Certification Impact** | Effect on Project Certification eligibility |
| 7 | **Decision** | Certification decision taxonomy (§5) |
| 8 | **Blocking Dependency** | Named prerequisite gate or AB/PCB |
| 9 | **Required Resolution** | What must change for gate satisfaction |
| 10 | **Authority Owner / Decision Owner** | Who may resolve |

**Prohibited:** PASS/FAIL-only judgment · ASSUMED CERTIFIED · score-based certification.

---

## 5. Certification Decision Taxonomy

| Decision | Definition |
|----------|------------|
| **CERTIFICATION_GATE_SATISFIED** | Current evidence satisfies this certification gate |
| **CERTIFICATION_GATE_PARTIAL** | Partially satisfied — explicit scope limitation documented |
| **CERTIFICATION_GATE_BLOCKED** | Prerequisite missing or acceptance blocker unresolved |
| **CERTIFICATION_GATE_PENDING_EVIDENCE** | Mechanism may exist; certification evidence incomplete |
| **AUTHORITY_DECISION_REQUIRED** | Engineering/documentation cannot decide — master authority must answer |
| **NOT_APPLICABLE** | Authoritative scope confirms gate does not apply |
| **PROJECT_CERTIFICATION_ELIGIBLE** | All mandatory gates satisfied **and** authority permits issuance |
| **PROJECT_CERTIFICATION_BLOCKED** | Mandatory gate not satisfied |
| **PROJECT_CERTIFICATION_AUTHORITY_GATED** | Technical state insufficient to decide issuance without authority |

**Prohibited:** ASSUMED CERTIFIED · CERTIFIED BY DESIGN · CERTIFIED BECAUSE PHASES COMPLETE.
