## 26. Rollback (EEP-ROLLBACK-001) — locked mechanism

**RPC write order (verified migration):**

```
STEP 2 reconcile → STEP 3 lock → STEP 4 double-check → STEP 5 identity
→ A → B → C → D → motion check → F → E marker → GATE-PROP → W → G → final verify
```

### Primary post-A–D rollback proof (mandatory)

**Mechanism:** Privileged concurrent marker race via **`pg` Session B** while **authenticated RPC Session A** is in-flight.

| Session | Action |
|---------|--------|
| **A** | Authenticated Supabase RPC on disposable fixture (valid source) |
| **B** | `pg` client: `UPDATE owner_vote_meetings SET snapshot_frozen_at = now() WHERE id = :meeting AND snapshot_frozen_at IS NULL` timed after A passes STEP 5 but before A commits |

| **Evidence** | No durable G · no marker from A · no partial A–D after A completes · evaluator **NO_FREEZE** or clean baseline |
