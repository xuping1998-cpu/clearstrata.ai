## 2. Migration idempotency (B)

| Statement class | Second-run behavior |
|-----------------|---------------------|
| `CREATE TABLE IF NOT EXISTS` | No-op |
| `ADD COLUMN IF NOT EXISTS` | No-op |
| FK `ADD CONSTRAINT` | Skipped if equivalent FK exists on column **or** orphan rows present |
| `CREATE INDEX IF NOT EXISTS` | No-op |
| `ENABLE ROW LEVEL SECURITY` | Idempotent |
| Baseline policy | Skipped if any policy exists on table |
| `GRANT` | Idempotent |
| `COMMENT ON` | Re-applied (metadata only) |

## 4. Pre-flight — existing FK inventory (D)

```sql
SELECT
  c.conname AS constraint_name,
  rel.relname AS table_name,
  a.attname AS column_name,
  pref.relname AS referenced_table,
  pg_get_constraintdef(c.oid) AS definition
FROM pg_constraint c
JOIN pg_class rel ON rel.oid = c.conrelid
JOIN pg_namespace nsp ON nsp.oid = rel.relnamespace
JOIN pg_attribute a ON a.attrelid = c.conrelid AND a.attnum = ANY (c.conkey) AND NOT a.attisdropped
JOIN pg_class pref ON pref.oid = c.confrelid
WHERE nsp.nspname = 'public'
  AND rel.relname = 'owner_vote_voter_snapshot'
  AND c.contype = 'f'
ORDER BY a.attname, c.conname;
```

**Migration behavior:** Adds named FKs only when no equivalent FK exists on `(meeting_id → owner_vote_meetings)` or `(property_id → properties)` and no orphans.

## 8. Rollback readiness (G)

| Action | Strategy |
|--------|----------|
| **Stop before apply** | Do not run migration; no DB change |
| **After apply — indexes/comments** | Leave in place; low risk |
| **After apply — FKs** | `ALTER TABLE … DROP CONSTRAINT IF EXISTS …` only if no dependent behavior requires them |
| **After apply — RLS policy** | Drop `ovvs_select_tenant_member` only if it was created (check `pg_policies`) |
| **After apply — column** | Do **not** drop `snapshot_frozen_at` — production depends on it |
| **Full revert** | Restore from backup; no down migration authored for IU-1.1 |
