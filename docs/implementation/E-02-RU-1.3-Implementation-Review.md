## 5. RA-RU-1.3-001 — C9 durable visibility

| Field | Value |
|-------|-------|
| **RA-RU-1.3-001** | C9 durable visibility rule |
| **Disposition** | **RESOLVED FOR IMPLEMENTATION READINESS** |

### 5.1 Locked C9 implementation rule

**C9 is `true` if and only if:**

1. Authority evaluation executes as a **fresh independent read** (new Supabase query round-trip — not in-memory RU-1.2 return payload).
2. That read observes **complete C1–C8** durable state for the authoritative primary freeze.
3. Evaluator session is **not** the RU-1.2 write transaction.

**Inference:** Post-transaction durable visibility of complete correlated A–G rows ⇒ earlier RU-1.2 transaction committed successfully.

### 5.2 Explicit C9 rejections (locked)

| Signal | C9 proof? |
|--------|-----------|
| In-function / pre-return visibility | **NO** |
| `transaction_reference_at` alone | **NO** |
| `created_at` alone | **NO** |
| RPC response / `ATOMIC_ENVELOPE_COMPLETE` | **NO** |
| Client acknowledgement | **NO** |
| Cached application rows without fresh read | **NO** |

Evaluator **does not** require persisted `committed_at`.

### 8.2 Simplification — `NOT_COMMITTED` omitted

After RU-1.2 single-transaction atomic model:

| Case | Status |
|------|--------|
| No E-02 authoritative footprint | **NO_FREEZE** |
| Partial / inconsistent durable footprint | **FAIL_CLOSED** or **CORRELATION_MISMATCH** |
| Generic non-corrupt absent state | **NO_FREEZE** |

**`NOT_COMMITTED` removed** — semantics fully covered without ambiguity.

### 8.3 Result type shape (locked)

Discriminated union aligned with snapshotDomain:

```typescript
type CommittedFreezeAuthorityResult =
  | { ok: true; data: CommittedFreezeAuthorityEvaluation }
```

| Field | Rule |
|-------|------|
| `CommittedFreezeAuthorityEvaluation.status` | One of locked union |
| `CommittedFreezeAuthorityEvaluation.authority` | `true` **iff** `status === 'COMMITTED'` |
| `CommittedFreezeAuthorityEvaluation.reason` | Human-readable + machine `code` |
| Fatal invariant violations | Return `{ ok: false, error }` — **do not throw** (snapshotDomain convention) |

**RETRYABLE / NEW_ATTEMPT_REQUIRED:** **Excluded** — RU-1.2 write-path only.

## 13. Executable C1–C9 predicates

### C1 — Authoritative primary event

| Field | Rule |
|-------|------|
| **Input** | `bundle.freezeEvent` · `bundle.readMode` · meeting id |
| **Check** | `readMode === 'event_linked'` AND `freezeEvent.isPrimary === true` AND `freezeEvent.ownerVoteMeetingId === meeting.id` AND `freezeEvent.propertyId === meeting.propertyId` |
| **Meeting entry** | From `loadFrozenMeetingBundleByOwnerVoteMeetingId` — primary resolved by repository |
| **Event entry** | Load event bundle · **additionally** verify `freezeEvent.id === primaryForMeeting.id` via second primary lookup or equivalent |
| **Success** | Authoritative primary identified |
| **Failure** | `readMode !== 'event_linked'` → **LEGACY_NOT_AUTHORITATIVE** · explicit non-primary → **NON_PRIMARY_EVENT** · no event → **NO_FREEZE** |

|-------|------|

| **Failure** | **FAIL_CLOSED** or **CORRELATION_MISMATCH** |
