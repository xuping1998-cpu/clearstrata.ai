## 10. Timestamp semantics (deep review)

| Concept | Authoritative semantics |
|---------|------------------------|
| **`freezeBoundaryAt`** | Logical governance freeze instant — persisted as `freeze_boundary_at` + marker fields |
| **`commitTimestamp`** | Durable evidence of successful transaction COMMIT — **recommended** dedicated `committed_at` populated with orchestration-assigned instant aligned to COMMIT success |
| **`created_at`** | Audit row insert time — may precede COMMIT instant · **insufficient alone** |

**Pre-COMMIT staging:** Audit row inserted in same transaction; `committed_at` may be set to envelope-assigned commit instant **at staging** with semantic authority confirmed only after COMMIT succeeds — alternatively populated from transaction commit timestamp at COMMIT boundary. Exact mechanism = **executable implementation obligation**; logical semantics **resolved** at design level.

**Strategy (approved):** Orchestration records intended commit evidence; durable meaning confirmed at COMMIT; rollback removes row — no false committed audit.
