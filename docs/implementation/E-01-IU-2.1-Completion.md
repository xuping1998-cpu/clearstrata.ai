## 3. Objective

Introduce the Blueprint §9 **Freeze Event** persistence layer with a stable globally unique identifier (INV-8) as the canonical correlation anchor for future immutable voter and resolution snapshots. Add nullable voter-snapshot correlation without changing freeze orchestration, RPC behavior, or snapshot population.

## 5. Database Changes

- **Migration:** `20261725120000_e01_iu21_freeze_event_identity.sql`
- **Tables:** `public.owner_vote_freeze_events` (new)
- **Columns:** `public.owner_vote_voter_snapshot.freeze_event_id` (nullable uuid)
- **Indexes:**
  - `owner_vote_freeze_events_one_primary_per_meeting` (partial unique — one primary per meeting)
  - `idx_owner_vote_freeze_events_meeting_id`
  - `idx_owner_vote_freeze_events_property_id`
  - `idx_owner_vote_voter_snapshot_freeze_event_id` (partial, non-null)
- **Constraints / FKs:**
  - `owner_vote_freeze_events.owner_vote_meeting_id` → `owner_vote_meetings(id)` ON DELETE CASCADE
  - `owner_vote_freeze_events.property_id` → `properties(id)` ON DELETE CASCADE
  - `owner_vote_voter_snapshot.freeze_event_id` → `owner_vote_freeze_events(id)` ON DELETE RESTRICT
- **RLS / policies:** RLS enabled on `owner_vote_freeze_events`; `ovfe_select_tenant_member` when no policies exist
- **Grants:** SELECT `authenticated`; ALL `service_role`
