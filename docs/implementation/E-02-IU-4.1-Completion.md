```
  → primary Freeze Event (repository: is_primary=true, newest created_at)
  → correlated event_linked bundle
```

## 9. Explicit event identity lookup baseline

**`loadByFreezeEventId(freezeEventId)`:**

```
known freezeEventId → exact Freeze Event → correlated bundle
```

**Does not require** `is_primary = true`.

**Successful load proves only:**

- Requested event exists
- Repository can load correlated frozen bundle

**Does not prove:**

| Claim | Proven? |
|-------|---------|
| Event is primary | **NO** |
| Current authoritative meeting freeze | **NO** |
| COMMITTED | **NO** |
| Primary Audit exists | **NO** |
| Successful durable DB COMMIT | **NO** |

**Permitted use:** historical · diagnostic · explicit-event identity reads.

**ARQ-015:** **RESOLVED** — no E-01 repository modification required.

## 12. No-live-reconstruction baseline

```
NO LIVE RECONSTRUCTION
```

Frozen repository reads **must not** reconstruct from:

- `property_members`
- `owner_vote_resolutions`
- Agenda authoring state
- Other mutable current governance sources

Missing frozen data → null / empty / failure / contract-defined incomplete — **not** live rebuild.

---

## 13. Correlation fail-closed baseline

`assertBundleCorrelation` is **mandatory**. Correlation mismatch → **FAIL CLOSED**.

**Prohibited:** cross-event merge · automatic repair · id replacement · parent substitution · live fallback · silent conflict suppression.

**Dimensions:** `freezeEventId` · `meetingId` · `propertyId` · resolution parent · voter event · motion event/parent.

---

## 14. Missing-data baseline

```
Readable ≠ Complete ≠ Authoritative Primary ≠ COMMITTED
```

Contract-permitted: `resolutionSnapshot = null` · `frozenMotions = []`

Must not trigger live reconstruction or committed-completeness inference.

```
repository read authority ≠ Phase 3 durable commit authority
```
