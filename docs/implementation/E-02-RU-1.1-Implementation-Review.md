## 5. RA-RU-1.1-001 — blocking closure

| Field | Value |
|-------|-------|
| **RA-RU-1.1-001** | **`committed_at` naming/semantics insufficient** |
| **Design Review approved replacement** | **`transaction_reference_at timestamptz NOT NULL`** |
| **Implementation Review disposition** | **RESOLVED FOR IMPLEMENTATION READINESS** |

### Mandatory semantic statement (locked)

```
transaction_reference_at
  = server transaction reference timestamp
  = populated at INSERT using transaction_timestamp()
  = durable ONLY IF the inserted row survives the same successful database COMMIT
  ≠ actual durable commit instant (WAL flush / post-commit clock)
  ≠ sole COMMITTED authority (PAF-15)
  ≠ post-commit updated
  ≠ committed_at (REJECTED column name)
```

Future migration **SHALL NOT** create `committed_at` for RU-1.1 unless new authority supersedes Design Review.

Implementation document §7 retains historical `committed_at` proposal — **superseded by Design Review §18**; Implementation Review adopts **`transaction_reference_at`** as sole physical column name.
