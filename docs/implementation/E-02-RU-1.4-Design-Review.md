## 22–23. Rollback · post-write failure — ERQ-1.4-005

**RPC write order verified** (migration):

```
STEP 2 reconcile → STEP 3 lock → STEP 4 double-check → STEP 5 identity (pre-write)
→ A → B → C → D → motion check → F → E marker → GATE-PROP → W → G → final verify
```

| Failure class | When | Rollback value |
|---------------|------|----------------|
| Pre-write (STEP 5, validation) | Before A | **NOT mid-envelope proof** |
| Post A–D | `marker_write_failed` · GATE-PROP · G/final verify | **Valid post-write rollback evidence** |

**Post-write mechanisms without RPC modification:**

| Mechanism | Evidence |
|-----------|----------|
| **Concurrent marker race** | Session 1 completes marker; Session 2 fails `marker_write_failed` after A–D | **TG-1 partial** |
| **Duplicate G at INSERT** | **Blocked by STEP 5** pre-check — not post-write |
| **GATE-PROP failure** | Theoretically post A–D/E — **not reachable** via normal RPC (server sets all property_ids) |

**RA-RU-1.4-005 — RESOLVED WITH NOTE:**

- **Mandatory:** prove **durable absence** after failed RPC (EEP-7)
- **Mandatory:** at least one **post-A write failure** path (marker race or documented alternative)
- **TG-1 OPEN:** full A–F rollback after partial G — **may remain untestable** without privileged corruption; document in evidence gap register

**Pre-write validation failure ≠ mid-envelope rollback proof** — **locked**.

## 27. Post-lock double-check (DC-001) — ERQ / TG-2

**Required behavior:** STEP 2 NONE → competitor commits → STEP 4 FULL after lock → **IDEMPOTENT_RETURN**.

**Deterministic harness difficulty:** Cannot pause production RPC between STEP 2 and STEP 3.

**Approved strategies:**

| Strategy | Validity |
|----------|----------|
| Probabilistic race (two RPCs + timing) | **Acceptable** if documented · may require repeated trials |
| Manual lock + privileged competitor commit + delayed RPC | **Complex** — Design Review accepts as research path |
| Sequential second call after full commit | **INVALID** — hits STEP 2 FULL, not STEP 4 |

**RA-RU-1.4-006 — RESOLVED WITH NOTE:**

- **TG-2 OPEN** for deterministic DC-001
- Evidence package must include **static code-path proof** (STEP 4 exists) **plus** runtime attempt
- **Does not block** RU-1.4 Design Review or IR if TG-2 documented with closure plan
