## 1. Purpose

Perform the formal Design Review for **E-02 IU-2.2 — Resolution Snapshot Materialization**.

Determine whether the proposed design correctly identifies production resolution authority, preserves the E-01 Resolution Snapshot domain, creates exactly one header per Freeze Event, establishes stable IU-2.3 parent identity, preserves the same freeze boundary and atomic envelope as IU-2.1, and contains no unresolved architecture or materialization semantics.

This review **shall not** certify executable implementation or runtime behavior.

No schema evidence supports `community_resolutions` or agenda-only rows as header authority.
