## 3. Core design question

**When may E-02 truthfully classify a freeze lifecycle as COMMITTED?**

Given:

- RU-1.2 RPC success returns **`ATOMIC_ENVELOPE_COMPLETE`** only
- Certified authority: **`ATOMIC_ENVELOPE_COMPLETE` ≠ COMMITTED**
- Client acknowledgement ≠ COMMITTED authority
- No single field ≠ COMMITTED authority
- Primary Audit alone ≠ COMMITTED authority

**Answer (design):** **COMMITTED** is a **deterministic authority conclusion** from **composite durable evidence** (9 certified components) after successful database transaction durability is established — evaluated by **read / verify / classify**, not by RPC return label alone and **not** by a mutable status flag.

## 4. Certified 9-part COMMITTED authority (recovered exactly)

Source: [`E-02-Phase-3-Certification.md`](E-02-Phase-3-Certification.md) §13 · [`E-02-IU-3.3-Completion.md`](E-02-IU-3.3-Completion.md) §10.

| # | COMMITTED evidence component | Source | Required? | Validation | Failure effect |
|---|------------------------------|--------|-----------|------------|----------------|
| **C1** | Authoritative primary Freeze Event | `owner_vote_freeze_events` | **Yes** | Exactly one row per meeting with `is_primary = true`; `id` correlates to all artifacts; `owner_vote_meeting_id` + `property_id` match meeting; `frozen_at` aligns to boundary | **NOT_COMMITTED** or **FAIL_CLOSED** if cardinality/correlation violation |
| **C2** | Complete Voter Snapshot | `owner_vote_voter_snapshot` | **Yes** | All rows for authoritative `freeze_event_id`; count ≥ 1 for E-02 materialized path; each row `property_id` = meeting property; count matches Primary Audit `voter_snapshot_count` | **FAIL_CLOSED** on mismatch; **NOT_COMMITTED** if absent |
| **C3** | Complete Resolution Snapshot | `owner_vote_resolution_snapshot` | **Yes** | Cardinality per audit: if `resolution_snapshot_count = 1` header MUST exist for event; if `= 0` only valid when motions count also 0 (non-materialized edge — not E-02 authoritative path) | **FAIL_CLOSED** if audit/cardinality inconsistent |
| **C4** | Complete Frozen Motions | `owner_vote_frozen_motions` | **Yes** | All rows for event; count matches audit `frozen_motion_count`; each row property matches; motion set consistent with audit materialization summary where present | **FAIL_CLOSED** on mismatch |
| **C5** | Freeze marker | `owner_vote_meetings.snapshot_frozen_at` | **Yes** | NOT NULL; equals authoritative event `frozen_at` and audit `freeze_boundary_at` | **NOT_COMMITTED** if null; **FAIL_CLOSED** if misaligned |
| **C6** | Primary Audit | `owner_vote_primary_freeze_audits` | **Yes** | Exactly one row per `freeze_event_id` (UNIQUE); immutable; identity + counts + boundary + `primary_event_is_primary = true` | **NOT_COMMITTED** if absent; **FAIL_CLOSED** if duplicate/corrupt |
| **C7** | A–G correlation / completeness | Cross-table | **Yes** | Same meeting · property · event · boundary across A–G; audit references match event | **FAIL_CLOSED** |
| **C8** | Exactly-one constraints | DB constraints + predicate | **Yes** | One primary event per meeting; one audit per freeze event; no orphan partial footprint without fail-closed classification | **FAIL_CLOSED** |
| **C9** | Successful durable database COMMIT | Implicit durability + audit reference | **Yes** | Durable rows visible post-transaction; `transaction_reference_at` populated on G; **no** open-transaction staged state | **NOT_COMMITTED** if rows not durable; staged-in-txn state never COMMITTED |

**Insufficient alone (certified):** `is_primary` · `snapshot_frozen_at` · `frozen_at` · `created_at` · **COMMIT_READY** · **COMMIT_SET_VERIFIED** · **COMMIT_PREPARED** · **AUDIT_PREPARED** · **COMMIT_AUTHORIZED** · **COMMITTING** · staged A–G in open transaction · client acknowledgement · **`ATOMIC_ENVELOPE_COMPLETE` RPC label**.

```
NO PRIMARY AUDIT → NO COMMITTED FREEZE
A–G COMPLETE ≠ COMMITTED (without C9 durability interpretation)
Successful durable DB COMMIT still required for COMMITTED (II-8)
```

## 5. Term chain preservation

Certified chain ([`E-02-Phase-3-Certification.md`](E-02-Phase-3-Certification.md) §14):

```
COMMIT_READY
≠ COMMIT_SET_VERIFIED
≠ COMMIT_PREPARED
≠ AUDIT_PREPARED
≠ COMMIT_AUTHORIZED
≠ COMMITTING
≠ COMMITTED
```

| State | Stage | Owner | Meaning |
|-------|-------|-------|---------|
| **COMMIT_READY** | Pre-transaction | Phase 2 hand-off | Materialization complete enough to enter commit path |
| **COMMIT_SET_VERIFIED** | Inside transaction | IU-3.1 / RU-1.2 pre-write | A–F correlation verified |
| **COMMIT_PREPARED** | Inside transaction | IU-3.1 | A–E staged · F verified · envelope open |
| **AUDIT_PREPARED** | Inside transaction | IU-3.2 / RU-1.2 | G staged · A–G verified · envelope still open |
| **COMMIT_AUTHORIZED** | Inside transaction | IU-3.3 orchestration | Final preconditions satisfied before commit |
| **COMMITTING** | Inside transaction | DB engine | Commit in progress / outcome not yet durably resolved |
| **ATOMIC_ENVELOPE_COMPLETE** | Post-RU-1.2 RPC return | RU-1.2 | Transaction succeeded · envelope written · **≠ COMMITTED label** |
| **COMMITTED** | Post-durable-evidence interpretation | **RU-1.3 authority evaluator** | Composite durable predicate satisfied |

**RU-1.3 scope:** post-transaction authority evaluation and orchestration interpretation — **not** collapsing pre-commit states into COMMITTED.

## 7. Post-transaction durable authority model

Evaluated options:

| Option | Assessment |
|--------|------------|
| **A. Same RPC result alone** | **Rejected** — client/RPC label ≠ COMMITTED (II-8 · CCA-19) |
| **B. Subsequent durable reconciliation query** | **Required component** |
| **C. RPC output + durable DB state** | **Preferred orchestration pattern** — RPC for write · separate read for authority |
| **D. Dedicated read-only authority function** | **Preferred server-side option** — extends RU-1.2 helper pattern |
| **E. Repository read layer alone** | **Insufficient alone** — READ COMPLETENESS ≠ COMMITTED (IU-4.2) |
| **F. Other certified mechanism** | None found beyond composite durable read |

**Design decision (proposed):** **C + D** — orchestration uses RU-1.2 write RPC; **COMMITTED** authority uses **read-only durable evaluation** (DB function and/or TypeScript authority layer reading same tables).

**Permanent:** **NO POST-COMMIT REPAIR.** **NO POST-COMMIT MUTATION** to mark COMMITTED.

## 25. Exact COMMITTED predicate (implementer-grade)

```
COMMITTED(meeting_id) IFF:

[C1] EXISTS exactly one primary freeze event E for meeting_id
     E.is_primary = true
     E.property_id = meeting.property_id

[C2] EXISTS voter snapshot set B where B.freeze_event_id = E.id
     count(B) >= 1  (E-02 path)
     ALL B.property_id = meeting.property_id
     count(B) = audit.voter_snapshot_count

[C3] IF audit.resolution_snapshot_count = 1
     THEN EXISTS resolution header C where C.freeze_event_id = E.id
          AND C.property_id = meeting.property_id
     ELSE IF audit.resolution_snapshot_count = 0
     THEN NOT EXISTS resolution header for E.id

[C4] EXISTS motion set D where D.freeze_event_id = E.id
     count(D) = audit.frozen_motion_count
     ALL D.property_id = meeting.property_id

[C5] meeting.snapshot_frozen_at IS NOT NULL
     meeting.snapshot_frozen_at = E.frozen_at = audit.freeze_boundary_at

[C6] EXISTS exactly one Primary Audit G where G.freeze_event_id = E.id
     G.owner_vote_meeting_id = meeting_id
     G.property_id = meeting.property_id
     G.primary_event_is_primary = true
     G.transaction_reference_at IS NOT NULL
     G.audit_kind = 'PRIMARY_FREEZE_AUDIT'
     G.commit_set_result = 'ATOMIC_SET_COMPLETE'
     G.transaction_outcome = 'ATOMIC_ENVELOPE_MEMBER'
     evidence JSONB fields populated (non-empty on E-02 path)

[C7] Cross-artifact correlation intact (meeting · property · event · boundary · attempt)

[C8] Exactly-one constraints satisfied (one primary · one audit per event)

[C9] All above rows durable (post-commit visibility) — not staged in open transaction

AND read_mode = event_linked (NOT legacy_meeting)

AND Artifact F evidence indicates status_mutated = false
```

## 26. COMMITTED failure classifications

| Classification | Meaning | Typical cause |
|----------------|---------|---------------|
| **COMMITTED** | C1–C9 satisfied | Authoritative E-02 freeze |
| **NOT_COMMITTED** | No durable authoritative envelope | No primary · no marker · no audit |
| **RETRYABLE** | Write-path only — active in-flight | RU-1.2 lock held elsewhere |
| **FAIL_CLOSED** | Partial / inconsistent durable state | Orphan rows · count mismatch · property mismatch |
| **LEGACY_NOT_AUTHORITATIVE** | `legacy_meeting` read mode | Pre-event-linked data |
| **CORRELATION_MISMATCH** | FAIL_CLOSED sub-class | RA-4.2-001 violation |
| **NON_PRIMARY_EXPLICIT_EVENT** | Event readable but not primary | Explicit lookup without primary authority |
