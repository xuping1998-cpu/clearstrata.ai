## 3. Objective

Establish the Blueprint §9 **Resolution Snapshot** persistence foundation: instrument header bound 1:1 to a Freeze Event, plus **Frozen Motion** rows holding immutable formal motion content metadata. No snapshot population, immutability enforcement, ballot identity, orchestration, or application changes.

## 5. Database Changes

- **Migration:** `20261727120000_e01_iu31_resolution_snapshot_foundation.sql`
- **Tables:**
  - `public.owner_vote_resolution_snapshot` (instrument header — 1:1 with freeze event)
  - `public.owner_vote_frozen_motions` (N formal motions per instrument)
- **Indexes:**
  - `owner_vote_resolution_snapshot_one_per_freeze_event` (unique)
  - `idx_owner_vote_resolution_snapshot_meeting_id`
  - `idx_owner_vote_resolution_snapshot_property_id`
  - `owner_vote_frozen_motions_snapshot_display_order` (unique per instrument)
  - `idx_owner_vote_frozen_motions_freeze_event_id`
  - `idx_owner_vote_frozen_motions_meeting_id`
  - `idx_owner_vote_frozen_motions_property_id`
  - `idx_owner_vote_frozen_motions_source_resolution_id` (partial, non-null)
- **Constraints / FKs:**
  - Resolution snapshot → `owner_vote_freeze_events(id)` ON DELETE RESTRICT
  - Resolution snapshot → `owner_vote_meetings(id)` ON DELETE CASCADE
  - Resolution snapshot → `properties(id)` ON DELETE CASCADE
  - Frozen motions → `owner_vote_resolution_snapshot(id)` ON DELETE CASCADE
  - Frozen motions → `owner_vote_freeze_events(id)` ON DELETE RESTRICT
  - Frozen motions → `owner_vote_meetings(id)` ON DELETE CASCADE
  - Frozen motions → `properties(id)` ON DELETE CASCADE
  - Frozen motions → `meeting_agenda_items(id)` ON DELETE SET NULL (nullable)
  - Frozen motions → `owner_vote_resolutions(id)` ON DELETE SET NULL (nullable)
- **RLS / policies:** RLS enabled; `ovrs_select_tenant_member`, `ovfm_select_tenant_member` when no policies exist
- **Grants:** SELECT `authenticated`; ALL `service_role`

### Schema objects created

| Object | Role |
|--------|------|
| `owner_vote_resolution_snapshot` | Resolution Snapshot entity — stable `id`, 1:1 with Freeze Event (INV-7) |
| `owner_vote_frozen_motions` | Frozen formal motion rows — title, text, order, threshold, method, source bindings |
