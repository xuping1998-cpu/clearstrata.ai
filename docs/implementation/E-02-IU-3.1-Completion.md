## 1. Purpose

This document records formal completion of **E-02 IU-3.1 — Atomic Commit**.

IU-3.1 establishes one authoritative engineering baseline:

**E-02 IU-3.1 — Atomic Commit Preparation Baseline**

This baseline defines how the certified Phase 2 **COMMIT_READY** hand-off is verified, staged, and handed off at local terminal state **COMMIT_PREPARED** — without final database **COMMIT**, Primary Audit persistence, or **COMMITTED** terminal state.

Downstream IUs **shall not** silently redefine this baseline.

This Completion Record certifies engineering design completion, implementation readiness, semantic closure, invariant closure, and IU-3.2 hand-off readiness.

It does **not** certify executable implementation, runtime persistence, transaction COMMIT, rollback execution, concurrency behavior, or production behavior.

## 5. Mandatory authoritative resolutions (baseline lock)

### 5.1 Artifact F = VERIFY-ONLY

```
IU-3.1 MUST NOT UPDATE owner_vote_meetings.status
```

| Rule | Requirement |
|------|-------------|
| Artifact F | Meeting lifecycle **compatibility verification only** |
| Prohibited | Create, infer, or use undocumented `"frozen"` status |
| Governance marker | `snapshot_frozen_at` is the E-02 freeze governance marker |
| Voting / open lifecycle | E-03 / E-04 — not IU-3.1 freeze commit |

**Source:** Design Review ACQ-003 / D-1 · Implementation Review §4 · §7F · **RA-3.1-001 RESOLVED**

### 5.2 Freeze Marker baseline

| Field | Value at staging |
|-------|------------------|
| `owner_vote_meetings.snapshot_frozen_at` | `freezeBoundaryAt` |
| `owner_vote_freeze_events.frozen_at` | `freezeBoundaryAt` |
| `owner_vote_freeze_events.is_primary` | `true` |

**Pre-commit guard:**

```
snapshot_frozen_at IS NULL
```

Otherwise: **FAIL CLOSED** — **RA-3.1-003 RESOLVED**

Marker staging ≠ **COMMITTED**. Marker staging occurs inside the same Phase 1 atomic envelope only.

### 5.3 Primary uniqueness baseline

**Index (authoritative):**

```
owner_vote_freeze_events_one_primary_per_meeting
ON (owner_vote_meeting_id) WHERE is_primary IS TRUE
```

| Rule | Requirement |
|------|-------------|
| Scope | **One primary Freeze Event per meeting** |
| Not reinterpreted as | Per attempt · per user · per boundary timestamp alone |
| Duplicate primary | **FAIL CLOSED** |

**Source:** Design Review ACQ-001

### 5.4 No legacy RPC

E-02 Atomic Commit path **shall not** invoke:

```
freeze_owner_vote_snapshot
```

| Status | Detail |
|--------|--------|
| Readiness | **RA-3.1-002 RESOLVED FOR READINESS** |
| Executable proof | Future Engineering Implementation Review obligation |

Legacy RPC **shall not** be used for voter snapshot generation, marker generation, freeze finalization, or commit preparation.

### 5.5 No live reconstruction

| Permitted | Prohibited |
|-----------|------------|
| Re-query staged/frozen snapshot artifacts (B–D) | Re-read `property_members` to rebuild eligibility |
| Verify Freeze Event · meeting row · constraints | Re-read `owner_vote_resolutions` for content |
| | Re-read agenda / live authoring state |

Incomplete staged artifact → **FAIL CLOSED** — no repair · no补数据.

**Source:** Design Review ACQ-007 · AI-7 · R-057

### 5.6 Commit timestamp distinction

| Concept | Role |
|---------|------|
| **`freezeBoundaryAt`** | Logical governance freeze boundary |
| **`commitTimestamp`** | Durable commit evidence / audit evidence |
| **`created_at`** | Row creation metadata — **not** full commit authority |
| **`frozen_at`** | Persisted logical freeze marker aligned to boundary — **not** alone full commit authority |

No invented `committed_at` / `finalized_at` column.

**Source:** Design Review ACQ-004

### 5.7 State separation (normative)

```
COMMIT_READY ≠ COMMIT_SET_VERIFIED ≠ COMMIT_PREPARED ≠ COMMITTED
```

| State | Owner |
|-------|-------|
| **COMMIT_READY** | Phase 2 terminal hand-off |
| **COMMIT_SET_VERIFIED** | IU-3.1 verification output |
| **COMMIT_PREPARED** | **IU-3.1 local terminal success** |
| **COMMITTED** | Phase 3 sequence after IU-3.2 + DB COMMIT |

**IU-3.1 NEVER produces COMMITTED.**

## 10. Rollback baseline

Any failure before **COMMITTED**:

```
FAIL CLOSED → ROLLING_BACK → rollback entire Phase 1 envelope → ROLLED_BACK
```

**Rollback scope includes:**

| Domain |
|--------|
| Phase 2 Voter Snapshot rows |
| Phase 2 Resolution Snapshot |
| Phase 2 Frozen Motions |
| Freeze Event staging / finalization |
| Freeze Marker staging (`snapshot_frozen_at`, `frozen_at`, `is_primary`) |
| IU-3.1 staged commit-preparation state |
| Future IU-3.2 staged Primary Audit |

**No meeting `status` staging exists under Artifact F verify-only — nothing to roll back on `status`.**

**Prohibited survivors:**

| Invalid partial state |
|-----------------------|
| Partial marker |
| Partial primary event |
| Partial snapshots |
| False **COMMITTED** evidence |

**Post-rollback retry:**

| Rule |
|------|
| New attempt |
| New `freezeEventId` |
| **No** reuse of abandoned candidate identity |

Full idempotent retry / concurrency semantics → **IU-3.3**.
