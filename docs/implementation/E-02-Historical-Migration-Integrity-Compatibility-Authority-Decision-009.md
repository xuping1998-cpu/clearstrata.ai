## 10. Family semantic scope

HOSCC may authorize **only** a Program-Authority-selected:

```
NARROW ORIGINAL-HISTORICAL-SQL COMPATIBILITY CORRECTION
```

Meaning (unchanged from PAD-058):

- the **original** historical source contains the clean-replay defect;
- exact origin restoration cannot solve it;
- missing-schema reconstruction is **not** the selected remedy;
- the historical SQL statement requires a **narrowly governed** compatibility correction;
- correction preserves intended historical semantics against the **historically proven** schema topology.

HOSCC is **not** generic authority to rewrite, modernize, restyle, or “improve” historical SQL; reconstruct missing schema; restore corrupted source; change application behavior; mutate runtime data; change quarantine; or perform DBA apply.
