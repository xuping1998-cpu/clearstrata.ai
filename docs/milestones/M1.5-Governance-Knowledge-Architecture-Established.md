## 1. Objective

Establish the **permanent constitutional documentation hierarchy** of the ClearStrata platform.

**Why:** Without a fixed knowledge pyramid, governance decisions, architecture, requirements, and code cannot be traced, audited, or kept constitutionally consistent.

---

## 2. Constitutional Basis

- **RC000** — platform evolution and CDGL
- **Appendix A (MGS)** — milestone recording standard
- **Appendix B (CGDP)** — documentation hierarchy (this milestone)

Strengthens RC000 by making **how knowledge is organized** as durable as **what the constitution says**.

---

## 3. CDGL Layer

**Cross-cutting** — CGDP applies to all CDGL layers (documentation meta-layer).

## 4. Scope

**Included**

- CGDP specification (LEVEL 0–6)
- RC000 Appendix B
- CGE Knowledge Dependency section
- Cursor CGDP gate

**Excluded**

- Application code
- Database schema
- Migrations
- Production behavior

**Boundary:** Documentation and Cursor rules only.

## 5. Architecture Changes

- Official **seven-level** knowledge pyramid: FD → RC000 → GDR → ADR → RC → Milestone → Implementation
- **Constitutional Dependency Rule** — lower layers cannot redefine higher layers
- **Baseline Locked** milestones as permanent references
