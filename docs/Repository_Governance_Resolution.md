## Repository Workflow

Before creating any permanent document, Cursor **SHALL**:

```
① Read RM-001 / FD-REG-001 Document Registry
    ↓
② Allocate the next available identifier
    ↓
③ Register the document
    ↓
④ Create the document
    ↓
⑤ Commit the Repository
```

Document numbers are **never guessed**, **never duplicated**, **never renumbered**.

## Repository Philosophy

The Repository is **more than source code**. It is the **constitutional memory** of ClearStrata.

Every document exists within a **larger constitutional ecosystem**. No official document stands alone.

Every official document shall contain **Related Documents** as a mandatory section — not merely for navigation, but to preserve constitutional relationships, institutional memory, and [The Beauty of Order](The_Beauty_of_Order.md) (GP-001).
