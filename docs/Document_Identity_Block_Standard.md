## Purpose

Every permanent document within the ClearStrata Repository shall begin with a standardized **Document Identity Block**.

The Identity Block provides:

- The **official identity**
- **Constitutional authority**
- **Version** and **status**
- **Historical relationship** of the document

It serves as the document's **permanent constitutional identity**.

---

## Required Identity Block

Every **official document** shall begin with:

| Field | Description |
|-------|-------------|
| **Document Number** | Permanent identifier (CS-001) |
| **Document Title** | Official title |
| **Document Type** | FD, CA, CS, GP, GC, CR, AI, AR, PR, RM, TM |
| **Status** | ACTIVE, RESERVED, DEPRECATED, SUPERSEDED, … |
| **Version** | Semantic or constitutional version |
| **Authority** | Governing document (usually FD-001) |
| **Effective Date** | ISO date of effect |
| **Classification** | Founding Documents, Constitutional Standards, … |
| **Owner** | Maintaining team or role |
| **Supersedes** | Prior document number, or `None` |
| **Superseded By** | Successor document number, or `None` |
| **Related Documents** | Cross-references (numbers or paths) |
| **Repository Location** | Path from repository root |

## Governance Principle

Every document should be **immediately identifiable**.

**Identity** creates **traceability**.  
**Traceability** creates **accountability**.  
**Accountability** protects **governance**.

---

### 核心原则

每一份正式文档，都应拥有 **唯一身份**。  
唯一身份，带来 **可追溯性**。  
可追溯性，带来 **责任**。  
责任，保障 **治理**。

## 统一格式（中文）

| 字段 | 说明 |
|------|------|
| **Document Number** | 文档编号 |
| **Document Title** | 文档名称 |
| **Document Type** | 文档类型 |
| **Status** | 状态 |
| **Version** | 版本 |
| **Authority** | 授权依据 |
| **Effective Date** | 生效日期 |
| **Classification** | 分类 |
| **Owner** | 维护责任方 |
| **Supersedes** | 替代文档 |
| **Superseded By** | 后续替代文档 |
| **Related Documents** | 关联文档 |
| **Repository Location** | 仓库路径 |

所有正式文档，首页必须包含统一的 **Document Identity Block**。

Document Identity Block 用于说明：文档身份、版本、权威来源、历史关系、仓库位置、以及生命周期。
