## Purpose

This Registry is the **single authoritative source** for every permanent document within the ClearStrata Repository.

Every constitutional document, governance document, project record, standard, and permanent repository document **must first be registered here** before creation.

This Registry preserves:

- **Constitutional authority**
- **Institutional memory**
- **Historical continuity**
- **Repository integrity**

**Narrative FD history:** [Founding_Documents_Registry.md](Founding_Documents_Registry.md) (institutional memory; **numbering authority remains this file**).

---

## Repository Rules

- ✓ Every permanent document shall appear here.
- ✓ Document numbers are **permanent**.
- ✓ Numbers are **never reused**.
- ✓ Numbers are **never renumbered**.
- ✓ **Cancelled** numbers remain **reserved**.
- ✓ **Historical references** remain valid **forever**.
- ✓ Cursor shall **always read this Registry** before allocating any permanent document number.
